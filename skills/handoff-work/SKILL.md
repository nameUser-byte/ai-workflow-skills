# 이어갈 수 있는 인계 기록

전체 대화의 복사보다 다음 작업자가 확인하고 실행할 수 있는 상태를 남긴다. 사용자가 요청하지 않은 새 대화·에이전트·원격 세션을 만들지 않는다.

## 작성 시점과 위치

사용자가 중단·인계를 요청했거나 맥락이 길어 핵심 결정이 사라질 위험이 있을 때 적용한다. 정상적인 매 메시지마다 문서를 다시 쓰지 않는다. 기존 작업 기록·인계 문서가 있으면 재사용하고, 파일 변경이 허용된 범위에서만 저장한다.

## 남길 내용

필요한 항목을 짧게 남긴다. 모든 항목에 긴 설명을 채울 필요는 없다.

1. **목표와 제약:** 최신 요구, 필수 결과, 남은 시간이나 마감이 실제로 알려진 경우 그 값.
2. **현재 상태:** 구현된 기능과 아직 실행하지 못한 기능. 관련 파일은 작업 폴더 기준 경로로 기록한다.
3. **중요 결정:** 선택한 방식, 이유, 정책·데이터 근거, 검토했지만 채택하지 않은 대안.
4. **검증:** 실제 입력·기대·관찰 결과와 근거 위치. 사용자 직접 검사와 AI 도구 검사를 구분한다.
5. **미해결:** 실패, 미확정 정책, 미검증 범위, 남은 한계. 임시 조치를 완료로 바꾸지 않는다.
6. **다음 행동:** 가장 먼저 할 구체적인 작업과 성공 확인 방법. 실행 명령은 당시 환경에서 확인된 경우에만 적는다.

서버가 실행 중인지, 어느 포트인지, 종료·재시작이 필요한지 확인된 상태만 적는다. 대화 재개가 앱 서버까지 복원한다고 가정하지 않는다. 인증 토큰·비밀번호·개인 대화 전체를 인계 문서에 넣지 않는다.

## 다시 시작할 때

인계 문서와 현재 파일을 대조한다. 이전 대화가 안 보인다는 이유로 작업이 삭제됐다고 단정하지 않는다. 확인된 기록 위치를 읽을 수 있으면 관련 범위만 확인하되 인증 파일을 탐색하지 않는다.

남은 시간·실행 상태·최근 변경을 확인하고 가장 먼저 해야 할 작업을 수행한다. 과거 인계의 ‘통과’는 과거 시점의 결과이므로 이후 변경과 관련 있으면 필요한 검사를 다시 실행한다. 불명확한 기록은 가정으로 표시한다.

Git 커밋이나 외부 공유는 이 Skill의 필수 단계가 아니다. 현재 과제의 도구 제한과 사용자 권한을 따르며, 인계를 이유로 Push·업로드·공개 게시를 추가하지 않는다.
