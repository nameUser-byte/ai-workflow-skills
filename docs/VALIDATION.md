# 검증 범위

확인일: 2026-10-31. 공개용 Skill과 비교 도구만 검증했다. 실제 시험 플랫폼·채점기·제출물에는 접속하지 않았다.

## 실제 실행한 검사

| 검사 | 결과 | 범위 |
|---|---|---|
| 공식 `skill-creator`의 `quick_validate.py` | 4개 Skill 모두 통과 | YAML, 이름, 설명, 미완성 틀 등 기본 형식 |
| `python -B -m unittest discover -s tests -v` | 10개 통과, 실패 0 | 아래 CSV 비교 동작 |

비교 도구는 Python 3.12.14 환경에서 검사했다. Python 표준 라이브러리만 사용하며 네트워크·브라우저·외부 AI에 접속하지 않는다.

실제로 검사한 동작:

1. 같은 ID와 순서, 한글·따옴표·줄바꿈 메모가 있는 CSV를 처리한다.
2. 화면에서 숨긴 취소 행이 CSV에 더 들어가면 불일치로 표시한다.
3. 행 수가 같아도 ID가 다르면 누락·추가 ID를 표시한다.
4. 중복 ID가 양쪽에 같게 있어도 그대로 통과시키지 않는다.
5. ID 순서 차이를 표시한다.
6. 화면이 비었고 CSV가 헤더뿐이면 일치로 처리한다.
7. 요청한 ID 열이 없으면 입력 오류로 처리한다.
8. CSV의 행 너비가 헤더와 다르면 입력 오류로 처리한다.
9. 입력 파일의 해시가 검사 전후 동일하다.
10. 실제 CLI 종료 코드가 일치 0 / 불일치 1 / 입력 오류 2로 나뉜다.

## 지침에 반영한 점

- 확정 정책과 가정·미확정을 구분하고, 실제로 받은 답과 출처를 남긴다.
- 화면의 관찰 목록과 CSV를 비교하며, 서버의 전체 목록을 화면 목록인 것처럼 사용하지 않는다.
- 인계 기록에 과거 검사·현재 상태·다음 행동을 구분한다.
- 설명 연습은 사용자 답변을 먼저 받고 실제 구현과 대조한다.
- AI 사용 금지 평가 단계와 자동 조작 제한을 존중한다.

위 항목은 작성된 지침의 설계와 내용 검토 결과다. 별도 모델을 실제로 실행해 모든 상황의 행동 준수를 검증했다는 의미는 아니다.

## 미검증·한계

- 자동 선택이 모든 Codex 버전·플랫폼에서 같은 시점에 일어나는지 검증하지 않았다.
- Skill의 형식 통과는 이해도 향상이나 시험 점수 상승을 증명하지 않는다.
- 사용자가 작성한 설명의 진위는 코드·실행 기록·실제 응답을 대조해야 한다.
- 비교 도구는 ID·행 수·중복·순서만 검사한다. 전체 셀 값·메모·화면 배치·저장 동작은 별도 검사다.
- 화면 ID를 수집하는 동작을 자동화하지 않았다. 실제 관찰과 다른 ID를 입력하면 화면·CSV의 일치를 증명할 수 없다.
- 공개 후보 5개는 원문과 커밋을 확인했으며, 외부 Skill 설치·실행과 실제 평가 환경 적합성은 검증하지 않았다.
- 직접 공개한 자료의 특정 시험 사용 허가는 해당 운영 규칙으로 별도 확인해야 한다.
